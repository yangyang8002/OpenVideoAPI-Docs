# 界面总览

管理后台入口默认 `/admin/`（可在初始化向导或服务器配置中修改）。登录后左侧导航包含：

| 页面 | 功能 |
| --- | --- |
| [控制台](/admin/console) | 访问总量、今日请求、在线 IP、弹幕 / 视频统计、性能监控与实时请求趋势 |
| 屏蔽词管理 | 屏蔽词增删、搜索、GitHub 词库订阅、一键刷新词库 |
| 弹幕列表 | 按视频码 / 内容筛选、分页浏览、删除弹幕 |
| 视频管理 | 添加 / 更新映射、批量删除、生成播放器快捷代码 |
| 字幕管理 | 添加（链接 / 文本 / 文件上传）、本地化、应用与取消 |
| [插件管理](/admin/plugins) | 插件安装（文件 / URL / npm）、启停、配置表单、插件市场 |
| [依赖与更新](/admin/deps) | 程序版本、npm 依赖逐个更新、插件更新 |
| [服务器配置](/admin/config) | 设置中心：9 个配置域（常规 / 主题 / 弹幕 / 视频 / 安全 / API / 数据库 / 备份 / 插件），支持搜索定位、即时校验与单项恢复默认 |
| 文件管理 | 浏览服务器文件、上传、压缩 / 解压、批量删除 |
| 日志 | 最近 500 条请求日志（方法 / 路径 / 状态 / IP / 耗时） |
| API 管理 | API 独立开关 / RPS / 带宽控制，1s 精度实时统计曲线 |
| [数据库管理](/admin/database) | 存储信息、切换存储与迁移、表数据浏览、导出备份 |
| [备份中心](/admin/backup) | 定时 / 手动备份、云端同步（FTP / SFTP / WebDAV / OpenList）、恢复 |
| [安全中心](/admin/security) | IP 异常检测、封禁 / 白名单、登录记录与防护、全球地图 |
| 关于 | 版本信息、检查更新、功能一览 |

## 界面语言

右上角（或初始化向导）可切换界面语言：简体中文、繁體中文、文言、English、日本語、Français，切换后立即生效并保存在本地。

## 主题

后台「服务器配置」中可选择后台主题与播放器主题（各 11 套），后台主题切换即时生效。详见 [主题系统](/admin/themes)。
