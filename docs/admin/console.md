# 控制台

控制台是后台首页，提供访问统计与性能监控。统计卡片每 2 秒自动刷新，请求趋势每 3 秒刷新。

## 统计卡片

| 卡片 | 说明 |
| --- | --- |
| 总请求数 | 自启动以来累计 API 请求数（持久化，重启不丢） |
| 总流量 | 累计响应字节数 |
| 访问 IP 数 | 去重后的访问 IP 总数 |
| 弹幕总数 | 当前存储的弹幕条数 |
| 视频映射 | 视频码映射数量 |
| 字幕数 / 屏蔽词 | 字幕库与屏蔽词数量 |
| 运行时间 | 服务持续运行时长 |
| 今日请求 | 今日（本地时区零点起）请求数 |
| 24h 在线 IP | 最近 24 小时活跃的访客 IP 数 |
| 今日弹幕 | 今日新发送的弹幕数 |
| 今日新视频 | 今日新增的视频映射数 |

## 性能监控

- **内存 (RSS)**、**堆内存**、**CPU 使用率**（由两次采样差分计算）
- **最近 1 分钟请求**：秒级桶累计
- **Node.js 版本**、**进程 PID**、**系统 / 磁盘**（总容量与已用）
- **折线图**：最近 20 分钟的内存与 CPU 趋势（服务端每 5 秒采样，保留 240 个采样点）

## 请求趋势

实时请求曲线（最近 30 分钟，秒级精度，每 3 秒刷新），展示总请求量与当前服务运行时长。
