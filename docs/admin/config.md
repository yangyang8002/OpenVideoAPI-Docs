# 服务器配置

26.10 起,「服务器配置」页升级为**设置中心**:全部运行配置按九个域分组展示,提供搜索定位、即时校验、单项恢复默认与未保存提醒,保存后相关配置立即重载,无需重启。

## 九个配置域

| 域 | 主要设置(括号内为默认值) |
| --- | --- |
| 常规 | 时区(Asia/Shanghai)、界面语言(zh / zhHant / wyw / en / ja / fr) |
| 播放器与主题 | 播放器主题(bili,共 11 套)、后台主题(md3)、CDN 开关与地址 |
| 弹幕 | 弹幕字数上限(500)、作者字数上限(50)、每 IP 每分钟条数(10)、渲染每秒上限(250)、速度抖动(10%) |
| 字幕与视频 | 字幕上传大小上限(200 MB)、预览大小(200 KB) |
| 安全与登录 | 会话时长(120 分钟)、后台入口路径、信任反向代理、自动封禁、异常与登录防护阈值、安全响应头、CORS、调试模式 |
| API 与限流 | PoW 开关与难度(关 / 4)、全局限流(关 / 60 次 / 60 秒)、API 统计保留天数(1 天) |
| 数据库 | 预留域(暂无设置项) |
| 备份与更新 | 自动备份(关)、间隔(24 小时)、保留份数(10)、备份内容(data / config) |
| 插件 | npm 镜像源、插件市场源(支持 `file://` 本地清单) |

## 界面能力

- **搜索定位**:输入关键词跳转到对应设置项
- **即时校验**:前端与后端共用同一套校验规则,失焦即提示
- **未保存提醒**:横幅显示「N 项设置未保存」,已修改项高亮;带未保存修改离开页面会二次确认
- **单项恢复默认**:每个设置项旁提供恢复默认按钮
- **分域锚点导航**:域名导航条,长表单快速跳转

## 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/settings` | 分域 schema、域名顺序与当前值 |
| POST | `/api/admin/settings/validate` | 保存前校验(`{values}` → `{errors}`) |
| POST | `/api/admin/settings/save` | 保存(键为全点路径如 `security.sessionMinutes`;未知键静默跳过;校验失败返回 `code: 2` 与逐项错误) |
| GET/POST | `/api/admin/config` | 旧端点,保留兼容 |

## 生效时机

- **安全域**(如 trustProxy)、**API 与限流域**(PoW、限流、弹幕、上传)、**备份域** 保存后立即重载或重算调度
- 主题切换即时生效
- `config.json` 文件结构保持不变,旧脚本与备份流程不受影响
